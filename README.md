> **Confidential projects:** Do not upload customer drawings, STEP models, proprietary interfaces or NDA material to a public GitHub Issue. Use the private engineering review form or email for customer-specific actuator development.

## Application Scenarios

SigGear ROS2 resources support:

- Humanoid robot joints
- Quadruped robot actuators
- Robot arm joints
- Robotic grippers and end effectors
- Research robot platforms
- CAN-based multi-actuator robotic systems
- Compact automation systems using ROS2 control architecture

SigGear's public joint modules are reference platforms. Customer-specific projects may require a different mechanical interface, motor, encoder, driver, communication setup or production configuration.
